# Memoria de IA — Multiservicios Las Acacias

Carpeta de contexto persistente para agentes que trabajen en este repositorio. No sustituye al código ni a `AGENTS.md`: guarda el "por qué" y el estado del proyecto.

## Archivos
- `contexto.md` — negocio, alcance y usuarios.
- `modulos.md` — requisitos funcionales por módulo y reglas de negocio.
- `arquitectura.md` — stack, entorno y restricciones técnicas.
- `decisiones.md` — decisiones tomadas y decisiones abiertas.
- `paleta-colores.md` — paleta y reglas de color del sistema (azul, blanco, rojo del logo).
- `diseno.md` — sistema de diseño profesional/futurista: tokens, shell, componentes, animaciones y datos demo.
- `progreso.md` — bitácora de sesiones y próximos pasos.

## Reglas
- Leer `contexto.md`, `modulos.md` y `arquitectura.md` antes de implementar.
- Registrar cambios relevantes en `progreso.md` con fecha.
- Registrar decisiones nuevas o pendientes en `decisiones.md`; no inventar definiciones.
- Si algo no está confirmado, escribirlo como **pendiente**, no como hecho.
- No guardar credenciales, tokens ni datos personales reales.
- Si esta memoria contradice el código o la configuración, gana el código; corregir la memoria.
